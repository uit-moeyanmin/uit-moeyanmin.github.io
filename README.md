## 📖 About

This is the official website of **Win Ko Ko Latt** (ဝင်းကိုကိုလတ်), also known as **သခင်ကြီး** (Thakin Gyi) and pen name **ဖိုးလောင်တီး** (Phoe Laung Tee). He is a prominent Myanmar nationalist activist, writer, and founder of the Anti-Tarzan Association (တောသားနှိမ်နင်းရေးအသင်း).

## ✨ Features

- 📱 **Fully Responsive** - Optimized for all devices (desktop, tablet, mobile)
- 🎨 **Modern UI/UX** - Beautiful animations and smooth transitions
- 🇲🇲 **Burmese Language** - Full Myanmar/Burmese language support with Padauk font
- 📝 **Blog Section** - Articles about nationalism, social ethics, and Myanmar culture
- 🖼️ **Photo Gallery** - Image gallery with lightbox functionality
- 📊 **Timeline** - Interactive journey timeline showcasing key life events

## 🛠️ Technologies Used

- HTML5
- CSS3 (Custom animations, Flexbox, Grid)
- JavaScript (Vanilla JS)
- [Padauk Font](https://fonts.google.com/specimen/Padauk) - Myanmar Unicode Font
- [Font Awesome 6.5](https://fontawesome.com/) - Icons
- [AOS Library](https://michalsnik.github.io/aos/) - Animate on Scroll
